# Porto Bakekok

A personal portfolio built with plain HTML and CSS. It has no build step or package dependencies, so it is easy to edit and publish as a static site.

## Make it yours

1. Update the intro and About copy in `index.html` as your bio or focus changes.
2. Update the project and stack details in the Work section.
3. The footer links point to [GitHub](https://github.com/M00rzey) and [LinkedIn](https://www.linkedin.com/in/mora-surya-premana-5540bb368/). The Say Hello section links to both contact emails; update the `mailto:` links in `index.html` if needed.
4. Add more project cards by copying the `.project-card` block and changing its text and illustration.
5. Adjust colors, spacing, and typography near the top of `styles.css`.

## Preview locally

From this folder, run:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

The page is a static site and can be published with GitHub Pages or any static hosting provider.
